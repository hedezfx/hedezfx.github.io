Set up by USB cable —

Works on every phone, including new Samsung phones. Use a Windows computer and a USB data cable. About 5 minutes.

  1. Start the phone freshUse a new or factory-reset phone. Skip the Google and Samsung accounts during setup. Wi-Fi and a screen PIN are fine.
  2. Turn on USB debuggingSettings → About phone (Samsung: Software information) → tap Build number 7 times. Then Developer options → turn on USB debugging.
  3. Plug the phone inUse a data cable. On the phone tick Always allow and tap Allow.
  4. Download and run the installerMade for .
    Open it. If Windows says "Windows protected your PC", click More info → Run anyway. Wait for the green DONE.
  5. Link the phoneOn the phone, scan this QR with the Camera → Copy. Open iSell Protect → paste → Enroll.
    Keep this code private — it is the phone's key.
  6. Check it workedThe phone's card shows "checked in just now" and the app says Protection: FULL.
