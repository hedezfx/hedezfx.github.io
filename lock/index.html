Set up by USB cable —

Works on every phone, including new Samsung phones where QR setup is blocked. Use this Windows computer and a USB data cable. It takes about 5 minutes.

  1. Start the phone fresh Use a new or factory-reset phone. Go through the setup screens, but tap Skip for the Google account and the Samsung account. Do not add any account, and do not set up Secure Folder.
    Wi-Fi is fine. A screen lock PIN is fine.
  2. Turn on USB debugging Samsung: Settings → About phone → Software information → tap Build number 7 times. Go back to Settings → Developer options (at the very bottom) → turn on USB debugging.
    Tecno, Infinix, itel and others: Settings → About phone → tap Build number 7 times, then Settings → System → Developer options → USB debugging.
  3. Plug the phone into this computer Use a cable that carries data (not a charge-only cable). A box appears on the phone: tick Always allow from this computer and tap Allow.
  4. Download and run the installer This installer is made for and the app file you uploaded.
    Open the downloaded file. If the browser asks, choose Keep. If Windows says “Windows protected your PC”, click More info → Run anyway. A blue window opens and does everything: it downloads the Android tools (first time only), downloads M&P Lock, installs it and gives it control of the phone. If the phone shows a Play Protect box, tap More details → Install anyway.
    Wait until the window turns green and says DONE. USB debugging switches itself off on the phone, so you can unplug it.
  5. Link the phone to this customer On the phone, open the Camera and point it at this QR → tap the text that appears → Copy. Open the M&P Lock app, press and hold the code box → Paste → tap Enroll.
    Keep this code private — it is the phone's key.
  6. Check it worked Within a minute this customer's card shows checked in just now. The app on the phone says Protection: FULL. Hand the phone to the customer.
Problems? What the blue window says and what to do
Phone NOT foundUse a different cable or USB port. Check USB debugging is on. Samsung phones may need the Samsung USB driver — install it, then press a key to try again.
The phone is asking for permissionUnlock the phone, tick “Always allow”, tap Allow, then press a key.
There is an account on the phoneSettings → Accounts and backup → Manage accounts → remove every account. Then run the installer again.
Another user or Secure FolderRemove Secure Folder / Dual Messenger, or factory-reset and redo step 1.
Phone already set upFactory-reset the phone and start again from step 1, skipping all accounts.
Download failedCheck the computer's internet and run the installer again.
Anything elseTake a photo of the blue window and send it to M&P Developers.

Set up by QR —

Best for older phones (Android 13 and below). New Samsung phones block QR setup — use USB setup for those. Use a new or factory-reset phone with no accounts signed in. On the very first welcome screen, tap the same empty spot 6 times. Connect to Wi-Fi when asked, then scan this QR. The phone installs M&P Lock and links itself to this customer.

Enrollment code

For a phone already set up with M&P Lock: open the app and paste this code (or scan the QR). Keep it private — it is the phone's key.
